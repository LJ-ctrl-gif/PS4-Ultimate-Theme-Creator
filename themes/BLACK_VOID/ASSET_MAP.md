# BLACK VOID — theme asset plan

Visual direction: near-black graphite, brushed silver highlights, crisp high-contrast silhouettes, transparent icon backgrounds.

## PS4 function slots
Use the builder's fixed IDs and export sizes:
- community — 128x128 PNG + 152x152 glow
- event — 128x128 PNG + 152x152 glow
- friend — 128x128 PNG + 152x152 glow
- message — 128x128 PNG + 152x152 glow
- notification — 128x128 PNG + 152x152 glow
- party — 128x128 PNG + 152x152 glow
- power — 128x128 PNG + 152x152 glow
- setting — 128x128 PNG + 152x152 glow
- trophy — 128x128 PNG + 152x152 glow

## Content slots
Export each selected content icon as 512x512 PNG. Prefer recognizable category artwork such as racing, football, basketball, sci-fi, adventure, music, video and arcade.

## Integration checklist
- [ ] Crop and inspect each source symbol as a separate transparent PNG.
- [ ] Match symbols to the fixed slot IDs; do not rename slots.
- [ ] Generate function glow variants at 152x152.
- [ ] Upload through the builder's Icons tab.
- [ ] Verify the Preview tab on both home and function screens.
- [ ] Build and validate the PKG with the builder's supported packaging tools.

The Firefly atlas is source artwork only; it is not itself a PS4 theme package.
