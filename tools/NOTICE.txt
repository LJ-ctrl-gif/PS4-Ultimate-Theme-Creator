PS4 packaging tool prerequisites
=================================

This directory intentionally contains no Sony publishing binaries.

The package builder requires these files in a supported Windows environment:

  tools/
    orbis-pub-cmd.exe
    ext/
      sc.exe
      di.exe

Optional audio helpers:

  tools/
    at9tool.exe
    ext/
      libatrac9.dll

These executables are proprietary software. This repository does not provide,
mirror, patch, or link to unofficial copies. Obtain any required tools only
through an authorized source and follow the applicable license terms. Do not
commit proprietary executables to this public repository.

The artwork generator and BLACK VOID preset export work without the packaging
executables. Producing an installable PS4 .pkg requires the supported Windows
packaging environment and all three required files above.
